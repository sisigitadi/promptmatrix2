# Short-Form Hook and Retention Formulas Reference

This reference documents viewer retention dynamics, hook formulas, and audio-visual coordination rules for short-form video platforms.

## 1. The 3-Second Retention Curve

Data across short-form platforms (TikTok, Reels, Shorts) demonstrates that the drop-off curve is steepest between second 0 and second 3. Overcoming this barrier requires simultaneous visual and verbal triggers:

```
Retention %
100% |  \
 80% |   \______
 60% |          \_________________ (Plateau: Goal is >65% at 0:30)
  0% +-----------------------------
     0s   3s    10s        30s   45s
```

## 2. High-Retention Hook Archetypes

| Archetype | Verbal Pattern | Visual Partner |
| :--- | :--- | :--- |
| **The Warning** | "If you are using [X], stop before [consequence]." | Screenshot of failure or warning log. |
| **The Secret Comparison** | "Junior engineers do [A]. Senior engineers do [B]." | Split-screen before and after. |
| **The Live Proof** | "Watch what happens when I run this in terminal." | Terminal full-screen with cursor blinking. |
| **The Unexpected Metric** | "This single line of SQL cut our query latency by 90%." | Benchmark bar chart zooming in. |

## 3. Disallowed Script Openers

Never start short-form scripts with these low-retention phrases:
- "Hey guys, welcome back..."
- "So today I wanted to talk about..."
- "Have you ever wondered..."
- Displaying an animated channel intro logo.
