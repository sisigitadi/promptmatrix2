# 🛠️ FAQ & Troubleshooting - PromptMatrix 2.0

### Q1: Tombol "Salin Prompt" tidak berfungsi di browser saya?
**Jawab**: Pastikan browser Anda memberikan izin clipboard (*Clipboard API*). Jika browser memblokir, Anda dapat memblok teks di dalam kotak output secara manual dan menekan `Ctrl + C` (Windows) atau `Cmd + C` (Mac).

### Q2: Mengapa isian form saya hilang saat me-refresh halaman?
**Jawab**: Formulir yang sedang aktif di layar dirancang untuk sesi peracikan langsung. Jika Anda ingin menyimpan racikan prompt yang berharga, klik tombol **"Simpan ke Koleksi"** di bawah output box sebelum berpindah atau me-refresh halaman.

### Q3: Bagaimana cara memindahkan koleksi prompt saya ke laptop/perangkat lain?
**Jawab**: 
1. Buka menu **Koleksi (Stash)** di header atas.
2. Klik tombol **Export JSON** untuk mengunduh file cadangan koleksi Anda.
3. Kirim file JSON tersebut ke perangkat baru Anda.
4. Di perangkat baru, buka PromptMatrix 2.0, masuk ke menu **Koleksi (Stash)**, lalu klik **Import JSON**. Seluruh prompt Anda akan langsung muncul!

### Q4: Apakah PromptMatrix 2.0 bisa digunakan secara offline?
**Jawab**: Ya! PromptMatrix 2.0 berjalan sepenuhnya di browser sisi klien (*Client-Side Progressive App*). Setelah halaman dimuat pertama kali, Anda dapat meracik prompt tanpa perlu koneksi internet aktif.
