# ❓ Pertanyaan yang Sering Diajukan (FAQ) - PromptMatrix 2.0

### Q1: Apa itu PromptMatrix 2.0?
**Jawab**: PromptMatrix 2.0 adalah generator dan panduan prompt AI berpemandu yang membantu siapa saja (dari pengguna awam hingga profesional) meracik instruksi prompt berkualitas tinggi dan terstruktur untuk berbagai kebutuhan (media sosial, bisnis, copywriting, gambar AI, video, coding, dan karir).

### Q2: Apakah saya harus paham istilah teknis seperti "RTF", "AIDA", atau "SOP"?
**Jawab**: **Sama sekali tidak.** Di PromptMatrix 2.0, seluruh formula telah disederhanakan menjadi bahasa manusia yang membumi. Anda cukup memilih kebutuhan Anda (misal: "Deskripsi Produk Shopee" atau "Hook Video TikTok") dan mengisi kolom yang diminta, atau klik tombol **"💡 Isi Contoh Otomatis"**.

### Q3: Bagaimana cara kerja tombol "💡 Isi Contoh Otomatis"?
**Jawab**: Tombol ini akan otomatis mengisi seluruh formulir dengan data skenario nyata yang relevan. Ini sangat berguna jika Anda bingung harus mengisi apa pada formulir yang kosong. Setelah terisi, Anda bisa langsung menyalinnya atau mengubah beberapa kata sesuai konteks Anda.

### Q4: Apakah data prompt saya disimpan di server luar?
**Jawab**: **Tidak.** Seluruh data form, prompt racikan, dan koleksi stash Anda tersimpan 100% secara lokal di browser Anda (*IndexedDB / LocalStorage*). Tidak ada data pribadi yang dikirim ke server kami, sehingga privasi Anda 100% aman.

### Q5: Bagaimana cara menggunakan hasil prompt di ChatGPT atau Claude?
**Jawab**: Cukup klik tombol **"📋 Salin Prompt"** di kartu hasil sebelah kanan, lalu buka ChatGPT/Claude dan tempel (*paste*) prompt tersebut ke kolom chat. Anda juga bisa mengklik tombol shortcut tool AI di bagian bawah kartu untuk membuka ChatGPT/Claude sekaligus menyalin prompt secara otomatis.

### Q6: Mengapa tampilan PromptMatrix 2.0 sekarang jauh lebih lega dan bersih?
**Jawab**: Kami telah merombak total antarmuka menjadi 2 Mode Tampilan terpisah (**Galeri Template** & **Studio Peracik 2-Kolom**) dengan tipografi modern (*Inter* & *JetBrains Mono*) dan ikon vektor bersih untuk memastikan kenyamanan visual maksimal di laptop, tablet, maupun smartphone.
